🏥 Multi-Disease Prediction System

🤖 AI-Powered Multi-Disease Prediction System is a Machine Learning application designed to predict the risk of 🩺 Fever, 🩸 Diabetes, and ❤️ Heart Disease based on health-related data.

🎯 Objective: Develop a single intelligent system that can analyze patient health information and provide probability-based disease risk predictions using Machine Learning.

✨ Key Features:

- 🩺 Fever risk prediction
- 🩸 Diabetes prediction
- ❤️ Heart disease prediction
- 🤖 Comparison of multiple Machine Learning algorithms
- 🏆 Automatic selection of the best-performing model
- 📊 Probability-based prediction results
- 🌐 Interactive Streamlit web application
- ⚡ Real-time predictions

🛠️ Built With: 🐍 Python • 🐼 Pandas • 🔢 NumPy • 🤖 Scikit-learn • 🌐 Streamlit
