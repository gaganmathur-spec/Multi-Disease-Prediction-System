🩺 Multi-Disease Prediction System

An AI-powered Machine Learning application designed to predict the risk of Fever, Diabetes, and Heart Disease using health-related data.

🎯 Objective

Build a single intelligent system that analyzes health information and provides probability-based disease risk predictions using Machine Learning.

✨ Features

- 🩺 Fever Risk Prediction
- 🩸 Diabetes Prediction
- ❤️ Heart Disease Prediction
- 🤖 Multiple ML Algorithm Comparison
- 🏆 Best Model Selection
- 📊 Probability-Based Results
- ⚡ Real-Time Predictions
- 🌐 Interactive Streamlit Web App

🛠️ Tech Stack

Python • Pandas • NumPy • Scikit-learn • Streamlit
